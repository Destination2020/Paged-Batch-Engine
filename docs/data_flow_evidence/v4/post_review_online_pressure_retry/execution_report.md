# M7 post-review execution report

The persistent language main path now performs one non-blocking all-or-nothing reservation for each request's actual acquired bundle bytes, visual staging bytes, and conservative external-KV block footprint before submitting it to Scheduler. Model weights and fixed workspace are reserved for the process lifetime; the Agent-owned KV capacity is frozen after model initialization. A batch resource guard releases data leases and every transient pool reservation on success, rejection, cancellation, deadline, or exception.

With staging capped at 1,000,000 bytes, six simultaneous 308px requests produced two admissions and four typed `unified_budget_exhausted` rejections. Peak staging was 991,232 bytes. After those two requests completed and released resources, a seventh request was admitted in the same PID; staging usage returned to zero. The language process then released the full external pool, leaving 64/64 slots and no leases. Existing M7 lane, demand-reserve, checkpoint/recompute/auto, aging, quarantine and 10,000-cycle tests remain the contract evidence; this run supplies the previously missing online attachment to real resources.
